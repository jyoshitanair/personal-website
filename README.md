⭐️*Vercel* - for the deployment

⭐️*Supabase* - A database to store like and messages data

⭐️*CSS* - to make it look nice!

Features
========================================
⭐️A guestbook to leave a short message that comes with a randomly generated image that I drew :D It picks it from a predefined array and then adds the message to a table so everyone across the world can see the messages :D


⭐️Projects that are sortable with tags and searches. It checks for key words and selected categories that are changed with useEffect everytime the categories or text changes. If the text is nothing it shows everything - I thought this was cool so you never have to use the enter button for submitting text!


⭐️A like button for my art that stores the total likes :D Uses supabase and a yes/no useState tracker to show the different button states. Once you reload the page though your considered a new user that can like again! (cause like im not making people create an account to enter my personal website T-T) Right now it only works with one project because I have to add more states - really looking forward to fix that up next update :D


⭐️Iframes for holding my speeches. yayayy :D you can see them . I had to use /preview on the links to make them look nice but they're still not all perfectly centered like I wish they were.


⭐️Cool animations :D using keyframes - Things like animating  the click and all the logos come out or changing color or making something spin/rotate - and framer motion - making things slide into place or the text coming in the home page :D


⭐️Pretty art :D - of my mascot hehe
